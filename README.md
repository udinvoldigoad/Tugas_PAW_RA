# Tugas Pengembangan Aplikasi dan Web

Repository ini berisi kumpulan tugas Pengembangan Aplikasi dan Web dari kelas
RA. Setiap folder tugas berisi source code, aset, dan dokumentasi yang
berkaitan dengan program yang dibuat.

## Daftar Tugas

### Tugas 2 - Website ITERA

Folder [`tugas2_PAW`](./tugas2_PAW) berisi website HTML sederhana tentang
Institut Teknologi Sumatera (ITERA). Di dalamnya terdapat:

- Halaman utama pada [`index.html`](./tugas2_PAW/index.html)
- Halaman berita pada [`berita.html`](./tugas2_PAW/berita.html)
- Logo ITERA pada folder `img`
- Dokumentasi PDF pada folder `docs`
- Hasil validasi W3C pada folder `W3C Validator`

Dokumentasi tugas dapat dibaca pada
[`tugas2_PAW/README.md`](./tugas2_PAW/README.md).

### Task 3 - Pendaftaran Membership Gym Belwis

Folder [`task_3`](./task_3) berisi website pendaftaran membership Gym Belwis.
Website ini terdiri dari:

- [`task_3/index.html`](./task_3/index.html): formulir pendaftaran membership
- [`task_3/detail.html`](./task_3/detail.html): halaman detail pendaftar
- [`task_3/style.css`](./task_3/style.css): stylesheet dan tampilan responsif
- [`task_3/docs`](./task_3/docs): screenshot halaman dan laporan PDF

Dokumentasi lengkap task 3 tersedia pada
[`task_3/README.md`](./task_3/README.md).
